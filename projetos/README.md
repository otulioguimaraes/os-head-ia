# Projetos

Cada projeto recebe uma ficha Markdown nesta pasta. Código, mídias e arquivos pesados permanecem fora do OS.

Uma ficha deve registrar: natureza `REAL` ou `DEMO`, objetivo, estado, próximos passos, caminho local, URL do repositório, fontes e decisões relacionadas. Projetos demonstrativos permanecem marcados como `DEMO` e não contam como estado real do usuário.
