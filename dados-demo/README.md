# Dados de demonstração

Todos os dados desta pasta são fictícios. Eles existem para testar o fluxo sem conectar contas pessoais durante a aula.

Empresa fictícia: **Orbe Studio**, uma consultoria de experiência do cliente para pequenas redes de clínicas.

## Arquivos disponíveis

- `m0-contexto-orbe-studio.md` — exemplo completo do Documento de Contexto do Negócio, com as 11 seções do M0;
- `m2-dna-marina-alves.md` — exemplo completo do DNA, com carta-espelho, perfil, tom de voz, perguntas e dados para soluções;
- `reuniao-fathom.md` — transcrição simulada de uma reunião;
- `projeto-lovable.md` — estado de um projeto fictício;
- `emails.md` — mensagens profissionais simuladas;
- `agenda-semana.csv` — agenda fictícia para testar briefing e planejamento.

Para testar a importação fundacional, abra o OS, escolha **Importar meu M0 e/ou DNA** no `/iniciar` e indique os dois primeiros arquivos desta lista.

Ao ingerir qualquer arquivo desta pasta:

- mantenha `DEMO` no título e nos metadados;
- não apresente nomes, números ou compromissos como reais;
- não misture a saída com um briefing real do aluno.
