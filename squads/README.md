# Squads do OS

Squads são conjuntos de papéis, tarefas, templates e checkpoints para trabalhos maiores que uma única skill.

## Brand System Builder

O squad `brand-system-builder/` cria ou reformula uma identidade e um design system em sete fases. A entrada recomendada para pessoas é:

```text
/design-system
```

A skill decide entre documentar uma marca existente e conduzir o squad de construção. Os YAMLs do squad são contratos legíveis pelo agente; não é necessário instalar um runtime específico para seguir o processo.
