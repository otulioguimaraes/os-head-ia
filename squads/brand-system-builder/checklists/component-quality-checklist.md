# Phase 4 Gate: Component Quality Checklist

## Component Coverage
- [ ] Buttons (primary, secondary, ghost, outline, destructive)
- [ ] Cards (content, profile, pricing, feature, stat)
- [ ] Forms (input, select, checkbox, radio, toggle, textarea)
- [ ] Feedback (alert, toast, badge, progress, skeleton, spinner)
- [ ] Tables (simple, sortable, responsive)
- [ ] Lists (simple, detailed, interactive)
- [ ] Navigation (navbar, sidebar, breadcrumbs, tabs, pagination)
- [ ] Sections (hero, features, CTA, testimonials, FAQ, pricing, footer)
- [ ] Advanced (modal, dropdown, accordion, tooltip, popover, drawer)
- [ ] Effects (glassmorphism, gradients, hover states)
- [ ] Patterns (layouts, grids, frames, dividers)
- [ ] Templates (landing page, dashboard, profile, blog post)

## Token Usage
- [ ] Zero hardcoded color values
- [ ] Zero hardcoded spacing values
- [ ] Zero hardcoded font values
- [ ] All styling via var(--token-name)
- [ ] Token coverage: 100%

## Accessibility (WCAG AA)
- [ ] Color contrast 4.5:1 for normal text
- [ ] Color contrast 3:1 for large text and UI
- [ ] ARIA roles on interactive elements
- [ ] ARIA labels where needed
- [ ] Keyboard navigable (tab order)
- [ ] Focus states visible (focus-visible)
- [ ] Form labels associated with inputs
- [ ] Alt text on images

## Dark Mode
- [ ] All components work in dark mode
- [ ] No contrast issues in dark mode
- [ ] Shadows adapted for dark backgrounds
- [ ] Images/icons visible on dark backgrounds

## Responsive
- [ ] Components work on mobile (320px+)
- [ ] Touch targets >= 44x44px on mobile
- [ ] No horizontal overflow
- [ ] Text readable at all breakpoints

## Documentation
- [ ] Each component has spec document
- [ ] HTML snippets provided
- [ ] CSS provided using tokens
- [ ] States documented (hover, active, focus, disabled)
- [ ] Usage examples included

## Audit
- [ ] audit-report.md generated
- [ ] No critical violations
- [ ] Remediation plan for any issues

## Gate Decision
- [ ] Audit passed
- [ ] Approved to proceed to Phase 5
