# Phase 1 Gate: Brand Strategy Checklist

## Positioning
- [ ] Brand name defined
- [ ] Area of activity documented
- [ ] Target audience identified with persona
- [ ] Value proposition clearly articulated
- [ ] 3+ differentiators listed
- [ ] Key messages defined (3-5)
- [ ] Competitive position mapped (3+ competitors)
- [ ] Market gap identified

## Archetype
- [ ] Primary archetype selected with rationale
- [ ] Secondary archetype selected
- [ ] Brand personality map completed (5 dimensions)
- [ ] Voice guidelines derived from archetype
- [ ] Do/Don't communication examples provided
- [ ] 3+ reference brands cited

## Manifesto
- [ ] Mission statement written
- [ ] Vision statement written
- [ ] 3-5 core values defined with descriptions
- [ ] Manifesto text written in brand voice (200-400 words)
- [ ] Content pillars defined (3-5)

## Brand Voice
- [ ] Tone spectrum defined (4 axes)
- [ ] Channel adaptation guidelines (per platform)
- [ ] Vocabulary do/don't lists

## Moodboard
- [ ] 10-15 keywords defined
- [ ] Emotional tone described
- [ ] Visual direction hints for Phase 2
- [ ] Reference brands/people listed
- [ ] Texture/material associations

## Gate Decision
- [ ] All documents reviewed by user
- [ ] Approved to proceed to Phase 2
